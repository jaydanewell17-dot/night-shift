NIGHT SHIFT — BUILD 8

Run by opening index.html in a modern desktop browser.

CONTROLS
WASD / Arrow Keys — move
E — interact
Hold E while standing at the coffee station — wipe the machine

BUILD 8 FOCUS
- Customers browse shelves before checkout.
- Customer movement respects store obstacles and other customers.
- Checkout is an interactive counter scene: drag each physical-looking item card onto the scanner.
- After scanning, drag payment to the cash drawer or card terminal.
- Work problems appear naturally as observations instead of a permanent chore checklist.
- Coffee cleaning uses a multi-stage interaction.
- Trash is carried from the bin to the front door and dumpster area.
- Cooler and shelf issues can be discovered by walking around the store.
- Existing detailed SVG assets are preserved.

This is a browser prototype and does not require a server.
